An end-to-end Natural Language Processing (NLP) project that classifies movie reviews as positive or negative using a Long Short-Term Memory (LSTM) neural network. The project demonstrates text preprocessing, sequence padding, model training, evaluation, and real-time inference through a Streamlit web application.
